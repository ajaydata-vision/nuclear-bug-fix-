## Ground Truth

- root_cause: The app only registers a new push token when tokenSentToServer is false, but after reinstall this flag is missing so the old stale token is used indefinitely.
- why_it_happens: On reinstall, device storage is wiped but the server still holds the old token. The token flag check prevents re-registration. The new token generated by the OS after reinstall is never sent to the server.
- accepted_fix: Always retrieve the current token on app start and compare it with the stored token; if different, send the new token to the server and update the stored value.
- rejected_fix_patterns:
  - delete the user token on reinstall by detecting it
  - force full re-login on token mismatch without fixing automatic refresh

## Evidence Signals

- strongest_signal: Notifications work after fresh install but stop after reinstall; token in server DB does not match current device token
- strongest_alternative_explanation: FCM/APNs service outage
- why_alternative_is_wrong: Only reinstalled users are affected; other users with the same devices receive notifications correctly
